YouTube Channel ID Generator

Paste one or more YouTube channel URLs (one per line). Get the Channel IDs in seconds.

No key set — using public CORS proxies (less reliable).
With a key, lookups go directly to YouTube's API (fast, reliable, no proxies). Get a free key: Google Cloud Console → create a project → enable "YouTube Data API v3" → Credentials → Create API key. Free quota is 10,000 units/day; most lookups cost 1 unit (custom /c/ and bare vanity names cost 100). Your key is stored only in this browser and never sent anywhere except Google.
